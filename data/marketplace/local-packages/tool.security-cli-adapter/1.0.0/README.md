# security-cli-adapter

Marketplace Tool package sample for security CLI adapters.

This package is intentionally marked `runtimeReady: false`. It exists to test:

- Tool classification in the resource market.
- Review metadata for external binaries.
- The boundary that Tool packages are displayed but not installed until the runtime contract is implemented.

Referenced real-world source:

- https://github.com/f1tz/mcp-for-security-python

Do not run security CLIs against systems you are not authorized to test.
