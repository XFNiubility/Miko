# Web Research Note

Use this skill when the user asks for a compact research summary based on web pages, documentation, or public references.

## Workflow

1. Identify the user's exact question and required freshness.
2. Gather only relevant sources.
3. Extract facts, constraints, dates, and contradictions.
4. Produce a short note with source-backed claims.
5. Separate confirmed facts from assumptions.

## Output Shape

- Summary: one paragraph.
- Key facts: short bullets.
- Risks or caveats: short bullets.
- Sources checked: list titles or domains.

Do not invent citations or imply a source was checked if it was not.
