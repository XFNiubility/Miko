# Code Change Brief

Use this skill when the user needs a concise implementation handoff after code edits.

## Checklist

1. State the behavior changed.
2. List the files intentionally touched.
3. Explain compatibility and persistence impact.
4. Record verification commands and results.
5. Note remaining risks or follow-up work.

Keep the handoff factual. Do not claim a check passed unless it was run.
