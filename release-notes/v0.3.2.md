# Miko v0.3.2

## Highlights

- Unified desktop data roots so app updates can preserve conversations, MCP configuration, user Skills, and workspace data.
- Split bundled resources from user-owned data in preparation for safer application updates, built-in resource updates, and marketplace installs.
- Added local marketplace and update manifest foundations for future cloud catalog and resource package updates.

## Notes

- User-owned data remains under the configured data root and must not be overwritten by release artifacts or updater flows.
- Built-in resources are expected to ship through bundled resources, not through user `data/skills` or `data/mcp.json`.
