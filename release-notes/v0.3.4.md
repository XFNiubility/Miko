# Miko v0.3.4

> Invalid historical release record: this version was created from an internal engineering version after the public Miko product line had already reached v1.2. The GitHub Release was deleted on 2026-08-03. Do not recreate or reuse this version for a public release.

## Updater signing key migration

This release establishes the new Miko updater signing key after the original release private key was unavailable.

Important:

- This is a one-time migration release.
- Existing installations from versions before `0.3.4` may not be able to install this release through the in-app updater because they trust the previous updater public key.
- Install this version manually from the Windows installer attached to the GitHub Release.
- After `0.3.4` is installed, future updater releases use the new key and can be installed normally from the app.

## Included changes

- GitHub Releases updater endpoint and signed updater artifacts.
- More reliable Windows NSIS tooling in the release workflow.
- Marketplace and managed resource workflows from the previous product release.

## Data preservation

Application updates replace the program installation files only. They do not intentionally remove or replace user data such as conversation history, projects, MCP configuration, user Skills, tools, installed resource state, or workspace files.
