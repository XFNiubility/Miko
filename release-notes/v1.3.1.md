# Miko v1.3.1

Miko v1.3.1 完成了桌面端数据分层、应用更新、资源市场、安全资源工作流和发布体系的整体收口。本版本重点提升安装与升级可靠性，确保用户配置、历史会话和工作区在应用更新后继续保留。

## 桌面端与数据保护

- 将程序安装目录、用户数据、运行缓存和默认工作区分离，避免覆盖安装或重新安装时清除用户内容。
- 默认工作区使用 `Documents\Miko\mikospace`，用户明确选择项目目录时始终优先使用所选目录。
- 修复安装环境中内置 Agent、Skill、Tool 和市场资源无法发现的问题。
- 优化会话输入工具栏的响应式布局，避免权限模式文字折行和运行按钮溢出。
- 卸载程序会停止 Miko 和 sidecar 进程，同时保留用户数据与工作区。

## 资源市场

- 提供本地优先、可连接云端的资源市场架构。
- Skill 支持预览、安装、启用、禁用、更新和卸载。
- MCP 资源只合并自身 Server 配置，不覆盖用户已有的 `data/mcp.json` 内容。
- 用户手动修改市场 MCP 后，更新和卸载操作会进行冲突保护，不会静默覆盖配置。
- 增加资源包哈希、签名校验、目录签名和安装状态持久化。
- 完善市场认证、角色权限、管理员审核和用户管理基础能力。
- 内置资源、市场安装资源和用户自定义资源保持独立所有权边界。

## 安全资源与 Agent 工作流

- 安全资源与项目同级，可关联到普通会话和探索模式会话。
- 支持手工内容、本地文件与目录、URL 以及从历史会话提取资源。
- 本地路径和网络引用遵循“先识别、后授权、再读取”的权限流程。
- 从会话提取资源时优先展示 Agent 整理后的可复用正文，原始会话材料保留为可追溯来源。
- 会话任务状态与资源提取的运行、等待授权、完成和失败状态保持一致。
- 模型不可用时明确标记基础整理降级，不再将基础拼装结果显示为 Agent 提炼成功。

## 对话、权限与记忆

- 修复流式响应已经输出最终内容后，Assistant 回答仍可能重复追加的问题。
- 保留无流式事件时的最终回答兼容路径。
- 改进 Skill 和工具调用期间的权限状态处理。
- 恢复桌面环境中的自动记忆提炼触发，并阻止临时子 Agent 输出生成独立用户记忆。
- 探索模式继续使用会话级黑板，并可读取当前会话关联的安全资源。

## 应用更新与发布可靠性

- 使用 GitHub Releases、签名更新包和 Tauri updater 完成桌面应用更新。
- Windows 正式发布使用 NSIS 安装包，并生成对应 `.sig` 与 `latest.json`。
- 安装更新前会停止桌面 sidecar，成功后自动重新启动 Miko。
- Release 标题、安装资产、构建产物、应用元数据和用户可见文案统一使用 Miko 品牌。
- 增加版本线、签名配置、资源命名、安装包新鲜度和 native 构建门禁。

## 升级说明

应用更新只替换程序文件，不应覆盖或删除：

- 历史会话和项目；
- 用户 MCP 配置；
- 用户创建的 Skill 和工具；
- 市场安装状态；
- 安全资源及其任务记录；
- 自动记忆；
- 工作区文件。

由于 updater 签名信任根已经更新，公开的 Miko v1.2 及更早版本可能无法直接验证本版本。遇到签名或更新源错误时，请从本 Release 手动安装 Miko v1.3.1。已经安装当前签名基线版本的客户端可以通过“设置 -> 关于 -> 检查更新”完成在线升级。
