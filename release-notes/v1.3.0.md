# Miko v1.3.0

Miko v1.3.0 is the next feature release after the public Miko v1.2 line. It consolidates the desktop storage model, application updater, resource marketplace, managed resources, security-resource workflows, and release tooling completed during this development cycle.

## Desktop data and upgrades

- Separates installed application files from user-owned data, cache, and workspace directories.
- Keeps conversation history, projects, MCP configuration, user Skills, marketplace state, security resources, memories, and workspace files outside the installation directory.
- Creates the default `Documents\Miko\mikospace` workspace only when no explicit project directory is selected.
- Preserves explicit project directories and normalizes legacy workspace paths.
- Keeps uninstall and reinstall flows from intentionally deleting user-owned data.

## Application updates

- Uses GitHub Releases and signed Tauri updater artifacts for desktop application updates.
- Publishes Windows NSIS updater artifacts and `latest.json` through GitHub Actions.
- Stops desktop sidecars before installation and relaunches the application after a successful update.
- Adds stricter release checks for updater signing, version alignment, artifact freshness, and Miko product branding.

Important signing-key migration note:

- Public Miko v1.2 and earlier builds may trust a previous updater key or may not have the finalized updater chain.
- Install Miko v1.3.0 manually from the GitHub Release if an older client cannot validate the in-app update.
- After v1.3.0 is installed, subsequent releases signed with the same key can use the normal in-app updater flow.

## Resource marketplace

- Adds a local-first resource marketplace architecture that can later connect to the hosted Miko marketplace.
- Supports packaged Skill installation, enable, disable, update, and uninstall flows.
- Supports MCP packages that merge only their own server entries into user `data/mcp.json`.
- Protects MCP entries after user modification and prevents silent marketplace overwrites.
- Adds resource preview, package hashing, signature verification, catalog refresh, and installed-state persistence.
- Keeps bundled resources, marketplace packages, and user-created resources in separate ownership layers.

## Skills, MCP, tools, and Agents

- Ships categorized built-in Skills, Agents, tools, and marketplace examples with the desktop package.
- Restores bundled resource discovery in normal installed builds.
- Standardizes user MCP configuration at `data/mcp.json`.
- Keeps the existing tool availability view and prepares Tool and Agent marketplace contracts for later releases.

## Security resources and Agent tasks

- Adds reusable security resources alongside projects without changing the board ownership model.
- Allows resources to be linked to any session, including exploration sessions.
- Supports manual resource descriptions, local files and directories, URLs, and extraction from existing conversations.
- Requires identification and authorization before reading referenced local or network resources.
- Shows resource extraction and workflow execution as classified Agent tasks in the conversation surface.
- Persists resource associations and task status across restarts.

## Conversation, permissions, and memory

- Fixes duplicate assistant messages when streamed output already contains the final response.
- Preserves fallback assistant output when no stream event was emitted.
- Improves permission-state handling around Skill and tool execution.
- Restores automatic memory extraction when the local feature gate is unavailable.
- Prevents temporary sub-Agent output from creating standalone user memories.

## Packaging and release reliability

- Uses Miko consistently in public Release titles, artifacts, build outputs, and executable metadata.
- Removes the obsolete legacy CLI entry and keeps `bin/kimo` as the canonical CLI entrypoint.
- Prevents stale installer signatures or updater manifests from being copied into a new local build.
- Uses the supported Windows Bun runtime target for sidecar compilation.
- Adds unified server, desktop, persistence, release, and native quality commands.
- Prevents future releases from using versions below the public Miko v1.2 product line.

## Data preservation

The application update replaces installed program files. It must not intentionally overwrite or remove:

- conversation history and projects;
- user MCP configuration;
- user-created Skills and tools;
- marketplace installation state;
- security resources and extraction tasks;
- memories;
- workspace files.
