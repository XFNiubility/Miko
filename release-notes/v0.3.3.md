# Miko v0.3.3

> Invalid historical release record: this internal engineering version is below the existing public Miko v1.2 product line and must not be used as a public release baseline.

## Highlights

- Added the Resource Marketplace foundation for browsing, installing, updating, enabling, disabling, and removing managed Skills and MCP packages.
- Added session-linked security resources with file import, reference recognition, authorization states, extraction tasks, and reusable conversation context.
- Separated bundled agents, Skills, tools, and marketplace resources from user-owned data so application updates do not overwrite user configuration or history.
- Improved Windows NSIS packaging, install-directory detection, default workspace creation, bundled resource discovery, uninstall behavior, and local updater testing support.

## Fixes

- Fixed packaged sidecar startup and marketplace ZIP operations by bundling the required `fflate` dependency.
- Fixed resource-update rollback so marketplace catalog rollback no longer targets bundled application data.
- Fixed automatic memory extraction so the desktop setting is honored without requiring an unavailable GrowthBook gate.
- Fixed session creation failures caused by missing or stale default workspace paths.

## Update Notes

- Application updates use the signed Tauri updater artifacts published with GitHub Releases.
- User conversations, MCP configuration, custom Skills, installed marketplace state, tools, agents, and workspace files remain outside the replaceable application layer.
- The Resource Marketplace and official resource synchronization remain separate from application updates.
